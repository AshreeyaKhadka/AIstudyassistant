# What’s on the Website

This project is an AI Study Assistant website that offers a complete learning experience for students. It combines study tools, AI support, career guidance, and progress tracking in one platform.

## Main Features

### 1. User Authentication
- Signup and login pages are available.
- Users can create accounts and access personalized features.
- Secure access is provided for private study and profile data.

### 2. Dashboard
- A dashboard home page gives users an overview of the platform.
- Navigation is organized so users can easily move between study features.
- The interface is designed to be simple and student-friendly.

### 3. AI Chat Assistant
- An AI chat section is available for asking questions and getting help.
- The chatbot supports study-related interactions and guidance.
- It is designed to act as an intelligent learning companion.

### 4. Career Compass
- A dedicated career guidance feature helps users explore career paths.
- Users can enter interests, skills, goals, and experience.
- The website provides AI-based career recommendations and growth suggestions.
- It also offers a roadmap-style guidance experience for future planning.

### 5. Exam Preparation
- The website includes an exam preparation section.
- Users can access study materials and support focused on exam readiness.
- This section helps learners prepare for academic assessments.

### 6. Quiz and Practice
- Quiz and MCQ practice features are included.
- Students can test their knowledge through interactive practice questions.
- This helps improve understanding and revision.

### 7. Revision Planner and Flashcards
- A revision planner section helps users organize study schedules.
- Flashcards are available for quick review and memorization.
- This makes revision easier and more structured.

### 8. Notes and Learning Resources
- Users can manage notes and study content.
- Upload and view materials are supported.
- PDF-based learning resources can be accessed within the platform.

### 9. Syllabus Explorer
- The website includes a syllabus exploration section.
- Users can browse content based on syllabus topics and units.
- This helps with structured learning and course understanding.

### 10. Focus Mode
- A focus mode experience is available for distraction-free studying.
- It helps users concentrate better during study sessions.

### 11. Profile and Settings
- Users have a profile section where personal details and progress can be managed.
- Settings are available for account and preference management.

### 12. Admin Panel
- An admin dashboard is included for management purposes.
- This allows administrative control over the application sections.

## Overall Purpose
The website is built to support students in learning, practicing, revising, planning their careers, and getting AI-assisted help in one place.

## Summary for Another User
If you want to review or explain the project to someone else, this website includes:
- AI-powered study assistance
- Career guidance and roadmap support
- Exam preparation tools
- Quiz and revision features
- Notes and syllabus-based learning resources

## Main APIs, Models, and Packages Used

### Backend (Server-side)
- Flask is used as the main web framework.
- SQLAlchemy is used for database models and database interaction.
- Flask-Login or similar authentication support is used for session-based user access.
- ChromaDB is used for vector storage and retrieval-based features.
- Gemini / Google AI APIs are used for AI-powered content generation and career analysis.
- OpenAI-style LLM integration may also be used depending on the service layer.
- PDF and file-upload support is handled through backend processing libraries.

### Frontend (Client-side)
- React is used for building the user interface.
- Vite is used as the frontend development and build tool.
- Tailwind CSS is used for styling and responsive UI design.
- React Router is used for page navigation.
- Axios or fetch-based HTTP requests are used to communicate with the backend API.
- Framer Motion or similar UI animation libraries may be used for smoother transitions.

### Main AI/ML Related Components
- Large Language Model (LLM) integration is used for chat and recommendation features.
- Embedding-based search is used through vector storage and retrieval.
- AI-powered features include career guidance, study assistance, and content generation.

### Commonly Used Packages
- Python packages such as Flask, SQLAlchemy, requests, and chromadb
- Frontend packages such as react, react-dom, vite, tailwindcss, and router libraries
